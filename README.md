# 🛡️ Minecraft Account Checker

A lightweight, secure, and fast web application built with **Flask** to validate Minecraft accounts efficiently. Designed with a clean interface and seamless cloud deployment.

---

## 🚀 Checker Website
You can access the website here:
🔗 **[Bitly Link](https://bit.ly/4shHOUv)**

---

## 📌 Features
* **Fast Validation:** Quick processing of account credentials.
* **Proxy Support:** Utilizes `PySocks` for reliable and secure network requests.
* **Clean UI:** Minimalist and responsive web interface built with HTML/CSS.
* **Cloud Ready:** Fully configured for deployment on modern cloud platforms like Railway.

---

## 🛠️ Tech Stack
* **Backend:** Python, Flask, Gunicorn
* **Networking:** Requests, PySocks
* **Frontend:** HTML5, CSS3

## ⚙️ Local Installation & Setup

If you want to run or test this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Ashgamer33484/Web-Demon.git](https://github.com/Ashgamer33484/Web-Demon.git)
   cd Web-Demon
   
2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   
3. **Run the application**
   ```bash
   python app.py

4. **Open in browser**
   Navigate to https://127.0.0.1:5000 or https://localhost:5000

## 📝 How It Works
1. User enters the account details or tokens on the web interface.
2. The backend script (validator.py) securely processes and validates the data using helper libraries.
3. The result is instantly displayed back to the user on the dashboard.
